
Нормализация исходных рыночных данных
=====================================


Для каждого источника создаётся отдельный нормализатор. Он распаковывает и считывает исходные файлы, приводит пригодные записи к единому внутреннему CSV-формату, отбрасывает ненужные и невалидные записи, сортирует результат по времени и сохраняет один файл результата обработки источника за исходную дату: `data/normalized/<source>/YYYYMMDD.csv`.

Внутренний формат и критерии фильтрации следует указать в основной документации (`docs/SPECIFICATION.md`).
Наличие нормализованного файла за некоторую дату является свидетельством произведенной нормализации, поэтому дополнительной фиксации в документации или реестре не требуется.
После успешной нормализации исходные файлы удаляются из проекта. При необходимости их внешний архив ведётся отдельно.
Поскольку новые исходные данные будут поступать ежедневно, следует предусмотреть пакетную обработку, при которой для каждого источника запускается свой нормализатор.
